## 2. Analyse Détaillée (CRITIQUES + HAUTES clés)

### 🔴 S1 — Refresh token : logout cosmétique + pas de rotation
`auth/handlers.rs:67` (logout) ne deny-list que le `jti` de l'**access** token. Le **refresh** token (cookie 7 jours) n'est jamais révoqué, et `refresh` (`:104`) émet une nouvelle paire sans invalider l'ancien. **Impact** : un attaquant ayant volé le cookie `refresh_token` garde un accès permanent — même après que la victime s'est déconnectée. C'est la faille la plus grave du backend.

### 🔴 S2/S3 — Supply-chain & CI cosmétique
`mobile/google-services.json` est tracé par git malgré le `.gitignore` (ajouté avant). La CI met `continue-on-error: true` sur **tous** les jobs de test et d'audit (`ci.yml:68,101`) → un PR avec CVE connues ou tests rouges passe vert. Aucune barrière automatique ne détecte la fuite Firebase.

### 🔴 P1/P2/P3 — Rendu 100 % dynamique, SEO nul
`export const dynamic = 'force-dynamic'` à la racine (`layout.tsx:9`) désactive SSG/ISR/CDN pour **toutes** les routes. La home et les fiches biens — les pages les plus SEO-critiques d'un site immobilier — sont entièrement des Client Components qui fetche au hydratation. Les robots reçoivent une coquille vide ; le LCP est reporté ; le cache edge est inopérant.

### 🔴 R1/R2/R3 — Le déséquilibre résilience
- **Web** : socle React Query résilient **mais** WebSocket nu (pas de reconnexion) et `useListings` en `fetch` nu sans `AbortController`/timeout.
- **Mobile** (cible principale en Guinée) : WebSocket résilient **mais** `QueryClient` minimaliste (cache 5 min, retry immédiat, pas d'`offlineFirst`) → l'app devient inutilisable hors-ligne après 5 min.

### 🟠 S4/S5/S6/S7/S8 — Durcissement backend
Clients `reqwest` sans timeout (Vault/WhatsApp → boot bloqué), CORS `*` par défaut, webhook Evolution ouvert si token oublié, pas de graceful shutdown, et `CorsLayer` sans `allow_credentials` alors que l'auth passe par cookies HttpOnly (si le front est cross-origin, les cookies ne partent pas ; si `*` est forcé avec credentials, faille).

### 🟠 C4-C8 — Images/runtime Docker
Images `:latest` (non reproductibles, supply-chain), backend buildé en `debug` et exécuté en prod (10× plus lent, asserts actifs), runtime en `root`, pas de `.dockerignore` côté `rust-backend/` (le `target/` de plusieurs Go + `.env` local partent dans le context de build), socket Docker monté dans Traefik (escalation si RCE).

```rust
// src/domain/auth/handlers.rs — logout : révoquer aussi le refresh token
async fn logout(
    auth: AuthUser,
    State(state): State<Arc<AppState>>,
    headers: HeaderMap,
) -> AppResult<axum::response::Response> {
    let mut conn = state.redis.clone();
    let now = jsonwebtoken::get_current_timestamp();
    let ttl = auth.exp.saturating_sub(now).max(1);
    let _: () = conn.set_ex(revoked_key(&auth.jti), 1, ttl).await?;

    // Révoquer le refresh token présent dans le cookie
    if let Some(rt) = headers
        .get(axum::http::header::COOKIE)
        .and_then(|v| v.to_str().ok())
        .and_then(crate::auth::cookie::refresh_from_cookie_header)
    {
        if let Ok(claims) = jwt::verify(&state.jwt_secret, rt, jwt::TokenType::Refresh) {
            let rttl = claims.exp.saturating_sub(now).max(1);
            let _: () = conn.set_ex(revoked_key(&claims.jti), 1, rttl).await?;
        }
    }
    // ... clear cookies (inchangé)
}
```

// 1. Vérifier la deny-list du jti (révocation/logout)

async fn shutdown_signal() {
    let ctrl_c = async { tokio::signal::ctrl_c().await.expect("ctrl_c"); };
    #[cfg(unix)]
    let terminate = async {
        tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate())
            .expect("SIGTERM").recv().await;
    };
    #[cfg(not(unix))]
    let terminate = std::future::pending::<()>();
    tokio::select! { _ = ctrl_c => {}, _ = terminate => {} }
    tracing::info!("shutdown signal received, draining in-flight requests");
}

const toggleFav = useMutation({

  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: ['favorites'] });
    const prev = queryClient.getQueryData(['favorites']);
